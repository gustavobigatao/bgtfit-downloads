# BGT Fit — downloads

Repositório só para distribuir o APK do [BGT Fit](https://bgtfit.com.br) enquanto
o app ainda não está na Play Store. Sem código-fonte aqui.

## Baixar

[**Baixar APK mais recente**](https://github.com/gustavobigatao/bgtfit-downloads/releases/latest/download/BGT-Fit.apk)

Link fixo: sempre aponta pra última versão publicada, sem precisar trocar a URL
em lugar nenhum (site, mensagens etc.) a cada atualização.

## Como funciona

Cada atualização do app vira uma nova *release* aqui, com o arquivo `BGT-Fit.apk`
anexado. O link `/releases/latest/download/BGT-Fit.apk` sempre resolve pra
release mais recente automaticamente — é assim que o GitHub Releases funciona,
não precisa de nenhuma configuração extra.
